## 📌 About The Project

The **Bank Management System** is a C++ console application designed to manage client information and perform essential banking operations.

The application uses file handling to save and retrieve client records, allowing information to persist between program executions.

## ✨ Features

| Feature | Description |
|---|---|
| 👥 **List Clients** | Display all registered clients and their account details. |
| ➕ **Add Clients** | Register new clients with their personal and account information. |
| 🗑️ **Delete Clients** | Remove existing client records. |
| ✏️ **Update Clients** | Modify client information. |
| 🔍 **Find Clients** | Search for a client using their account number. |
| 💰 **Deposit** | Add money to a client's account balance. |
| 💸 **Withdraw** | Withdraw money from a client's account balance. |
| 📊 **Total Balances** | Display the total balances of all clients. |

## 🛠️ Technologies & Concepts

- 💻 **C++** — Core programming language.
- 📦 **Structures and Enums** — Organizing client data and defining options.
- 🔄 **Functions** — Separating operations into reusable functions.
- 📚 **STL Vectors** — Managing collections of client records.
- 📂 **File Handling** — Reading and writing client data using `fstream`.
- 🖥️ **Console I/O** — Handling user input and displaying results.

## 💾 Data Storage

Client records are stored in `Clients.txt`.

The application uses file operations to read, add, update, and delete client information.

## 🚀 Getting Started

### ✅ Prerequisites

- Windows
- Visual Studio with the C++ development workload installed

### 📥 Installation

**1. Clone the repository**

```bash
git clone https://github.com/Sarah-Nabil/Bank-Management-System-Cpp.git
```

**2. Open the project**

Open `BankProjectC++.sln` in Visual Studio.

**3. Build and run**

Build the solution, then run the application to start using the banking system.
