# Bank Management System – C++ Console Application

A console-based Bank Management System developed using C++ that allows users to manage bank client records and perform basic banking operations. The application uses file handling to store and retrieve client data.

## Features

- **List Clients:** Display all registered clients and their account information.
- **Add Clients:** Register new clients with their account details.
- **Delete Clients:** Remove existing client records.
- **Update Clients:** Modify client information.
- **Find Clients:** Search for a client using their account number.
- **Deposit:** Add money to a client's account balance.
- **Withdraw:** Withdraw money from a client's account balance.
- **Total Balances:** Display the total balances of all clients.

## Technologies Used

- C++
- Standard Template Library (STL)
- File Handling (`fstream`)
- Vectors and Structures
- Functions and Enums
- Console Input/Output

## Data Storage

The application uses a text file (`Clients.txt`) to store client records. Client information is saved and retrieved using file handling, allowing data to persist between program executions.

## Getting Started

### Prerequisites

- Windows operating system
- Visual Studio with C++ development tools installed

### Installation and Execution

1. Clone the repository:

   ```bash
   git clone https://github.com/Sarah-Nabil/Bank-Management-System-Cpp.git
   ```

2. Open `BankProjectC++.sln` in Visual Studio.

3. Build the solution.

4. Run the application.

## Project Structure

- `BankProjectC++.cpp` – Main source code and application logic.
- `Clients.txt` – File used to store client records.
- `BankProjectC++.sln` – Visual Studio solution file.
- `BankProjectC++.vcxproj` – Visual Studio C++ project configuration.
